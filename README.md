## GitHub Pages

이 저장소는 별도 빌드 과정 없이 루트의 `index.html`을 그대로 제공합니다. GitHub 저장소에서 **Settings → Pages → Build and deployment**로 이동해 `Deploy from a branch`를 선택하고, `main` 브랜치의 `/(root)`를 지정하면 게시할 수 있습니다. 게시가 완료되면 같은 설정 화면에 표시되는 주소에서 페이지를 확인하고 공유하세요.

일정 확인 체크 항목은 현재 기기의 브라우저에 저장됩니다. 공유 버튼은 휴대폰의 공유 메뉴를 열며, 메뉴에서 카카오톡을 선택할 수 있습니다.
